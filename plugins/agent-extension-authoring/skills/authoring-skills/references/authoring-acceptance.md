# Skill authoring acceptance criteria

- Name matches its directory; description states what the skill does and when to use it.
- First action, critical constraints and relevant resource routes are visible early.
- Long entry points and references have useful early navigation; links resolve.
- Script/reference/asset ownership matches source versus installed representation.
- Installed commands work with source resources unavailable.
- Routing evals have real booleans; task-success evaluations preserve expected behavior.
- Generation failures return nonzero before writing output; pending links remain incomplete.
- Audits preserve file contents; warnings and failed scans remain visible.
- At least three representative scenarios inform instructions, with real model coverage recorded.
- Review edits preserve triggers, constraints, commands, examples and verification loops.
- AI review checks language efficiency and unnecessary history separately from structural rules.
- Exact-path permission is obtained before deleting, renaming or relocating existing assets.
